# This fork has moved

The work that started here continues as **[Syntex](https://github.com/SergeiAK/syntex)** — a video player for Android TV boxes and a library on a home NAS, built on the Just+ Player 2.0.11 source, with its own package (`com.syntex.player`), releases and in-app updates.

Get it from [Syntex releases](https://github.com/SergeiAK/syntex/releases). Everything that was in this fork is there, and much more since: faster SMB, seek preview, pictures and frames in the browser, frame rate matching on by default, LAMPA's playlist contract, a software decoder for old formats.

This repository is kept read-only for its history and for the links from the issues where it was mentioned. For the official Just+ Player, see [just-plus-player/just-plus-player](https://github.com/just-plus-player/just-plus-player).
